# Kitaplikdefter v1.0.0

The first public release of Kitaplikdefter!

### Features
- Book and notebook-style note-taking
- Multi-page note system
- Text highlighting
- Quick access to marked lines
- Local storage

### Installation
1. Download `Kitaplikdefter-v1.0.0.zip`.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run `KitaplikDefter.exe`.

**Important:** Your notes are stored locally. Back up your data before uninstalling the application.

Enjoy!
